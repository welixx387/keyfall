# KEYFALL — магазин и раздача ключей Steam

Витрина с анимациями, оплата криптой через **@CryptoBot** (Crypto Pay API), бесплатные раздачи и админка для загрузки ключей.

## Публикация на Vercel

1. **Подключите базу данных.** Vercel → ваш проект → вкладка **Storage** → **Create Database** → **Neon** (бесплатный план) → **Connect** к проекту.
   Vercel сам добавит переменную `DATABASE_URL`. Таблицы создадутся автоматически при первом запросе.
2. **Задайте переменные.** Settings → **Environment Variables**:
   - `CRYPTO_PAY_TOKEN` — токен из @CryptoBot → Crypto Pay → Мои приложения;
   - `ADMIN_PASSWORD` — пароль от админки, придумайте свой.

   Остальные переменные из таблицы ниже необязательны.
3. **Перезапустите деплой:** Deployments → последний деплой → **⋯** → **Redeploy**.
4. Откройте `https://ваш-проект.vercel.app/admin`, войдите и загрузите игры. Чтобы посмотреть дизайн на примерах, нажмите
   Настройки → «Загрузить демо-витрину».
5. **Включите вебхук**, чтобы оплаты засчитывались мгновенно: @CryptoBot → Crypto Pay → Мои приложения → ваше приложение →
   Вебхуки → Включить → вставьте `https://ваш-проект.vercel.app/api/cryptopay/webhook`. Готовый адрес показан в админке
   на вкладке «Настройки».

Без вебхука оплата тоже засчитается: сайт сверяет счета, пока покупатель смотрит страницу заказа, и попутно с другими запросами.

## Запуск на своём компьютере

Нужен Node.js 22 или новее.

```bash
npm install
cp .env.example .env   # впишите токен CryptoBot и пароль админки
npm run seed           # необязательно: демо-витрина
npm start
```

- Магазин: http://localhost:3000
- Админка: http://localhost:3000/admin

Без `DATABASE_URL` используется встроенная база в папке `data/pg`: ничего устанавливать не нужно.
Если вписать в `.env` строку `DATABASE_URL` от Neon, локальный сервер будет работать с той же базой, что и сайт на Vercel.

## Демо-данные

Демо-витрина состоит из 13 игр с картинками из Steam и **ненастоящими** ключами вида `DEMO-XXXXX-XXXXX`.
Демо-товар «покупается» кнопкой «Симулировать оплату», без CryptoBot: так можно пройти весь путь покупателя до выдачи ключа.

Перед запуском удалите демо-игры: **Админка → Настройки → Удалить демо-игры и демо-заказы**. Ваши настоящие игры и заказы при этом не тронутся.

## Как добавить игру и ключи

1. Админка → «Игры и ключи» → «+ Добавить игру».
2. Вставьте ссылку на игру в Steam и нажмите «Подтянуть». Название, обложка, описание, жанры и цена в Steam подставятся сами.
3. Укажите свою цену. Старая цена нужна только для показа скидки.
4. Вставьте ключи, по одному в строке. Дубликаты отсеиваются автоматически.
5. Режим «Раздача» делает игру бесплатной: посетитель зажимает кнопку и забирает ключ.

Добавить ключи к существующей игре можно кнопкой «+ Ключи».

## Как проходит оплата

1. Покупатель жмёт «Купить». Сайт **бронирует** за ним один ключ и создаёт счёт в @CryptoBot (по умолчанию на 15 минут).
   Бронь атомарная: два покупателя не получат один и тот же ключ, даже если нажмут «Купить» одновременно.
2. Счёт можно оплатить в Telegram, в браузере или по QR-коду.
3. После оплаты ключ появляется на сайте с анимацией. Он **также приходит покупателю в чат @CryptoBot** (скрытое сообщение счёта), даже если тот закрыл сайт.
4. Если счёт не оплачен вовремя, бронь снимается и ключ возвращается в продажу.

Если оплата пришла в момент, когда ключи закончились, заказ получает статус «Оплачен, нет ключа». Когда вы добавите ключи этой игры, он выдастся автоматически.

## Настройки

На Vercel их задают в Settings → Environment Variables (после изменения нажмите Redeploy), на своём компьютере — в файле `.env`.

| Параметр | Что значит |
|---|---|
| `DATABASE_URL` | строка подключения к Postgres; на Vercel добавляется сама при подключении Neon |
| `CRYPTO_PAY_TOKEN` | токен приложения из @CryptoBot → Crypto Pay |
| `ADMIN_PASSWORD` | пароль от админки |
| `CRYPTO_PAY_NETWORK` | `mainnet` (реальные деньги, по умолчанию) или `testnet` (@CryptoTestnetBot) |
| `PUBLIC_URL` | адрес сайта; на Vercel определяется сам, задайте, если подключили свой домен |
| `SHOP_NAME` | название магазина на сайте |
| `FIAT` | валюта цен: `USD`, `EUR`, `RUB`… |
| `ACCEPTED_ASSETS` | какими монетами можно платить, через запятую |
| `INVOICE_TTL_MIN` | сколько минут живёт счёт и бронь ключа |
| `GIVEAWAY_COOLDOWN_HOURS` | как часто один посетитель может забирать бесплатный ключ |
| `SUPPORT_URL` | ссылка на поддержку (например, `https://t.me/ваш_ник`), появится в футере и FAQ |
| `TRUST_PROXY` | `true`, если сайт стоит за nginx или Cloudflare (на Vercel включается сам) |

## Безопасность и бэкапы

- Токен CryptoBot и пароль храните только в переменных окружения или в `.env`. Файл `.env` не попадает в git (он в `.gitignore`).
  Если токен куда-то утёк, создайте новый в @CryptoBot и замените его.
- Все игры, ключи и заказы хранятся в базе данных. У Neon есть автоматические резервные копии (раздел Backup & Restore в его панели).
- Раздачи ограничены по IP: один ключ из каждой раздачи и не чаще раза в `GIVEAWAY_COOLDOWN_HOURS` часов.

lib/cryptopay.js     клиент Crypto Pay API
lib/demo.js          демо-витрина
scripts/seed.js      загрузка демо-витрины из командной строки (npm run seed)
vercel.json          маршруты для Vercel
public/index.html    витрина          public/js/app.js     её логика и анимации
public/admin.html    админка          public/js/admin.js   её логика
