# KEYFALL — магазин и раздача ключей Steam

Витрина с анимациями, оплата криптой через **@CryptoBot** (Crypto Pay API), бесплатные раздачи и админка для загрузки ключей.

## Запуск

Нужен Node.js 22 или новее.

```bash
npm install
cp .env.example .env   # впишите токен CryptoBot и пароль админки
npm run seed           # необязательно: демо-витрина
npm start
```

- Магазин: http://localhost:3000
- Админка: http://localhost:3000/admin (пароль лежит в файле `.env`, строка `ADMIN_PASSWORD`)

## Демо-данные

В магазин загружены 13 демо-игр с картинками из Steam и **ненастоящими** ключами вида `DEMO-XXXXX-XXXXX`.
Демо-товар можно «купить» кнопкой «Симулировать оплату» без CryptoBot. Так можно посмотреть весь путь покупателя до выдачи ключа.

Перед запуском удалите их: **Админка → Настройки → Удалить демо-игры и демо-заказы**. Ваши настоящие игры и заказы при этом не тронутся.

## Как добавить игру и ключи

1. Админка → «Игры и ключи» → «+ Добавить игру».
2. Вставьте ссылку на игру в Steam и нажмите «Подтянуть». Название, обложка, описание, жанры и цена в Steam подставятся сами.
3. Укажите свою цену. Старая цена нужна только для показа скидки.
4. Вставьте ключи, по одному в строке. Дубликаты отсеиваются автоматически.
5. Режим «Раздача» делает игру бесплатной: посетитель зажимает кнопку и забирает ключ.

Добавить ключи к существующей игре можно кнопкой «+ Ключи».

## Как проходит оплата

1. Покупатель жмёт «Купить». Сайт **бронирует** за ним один ключ и создаёт счёт в @CryptoBot (по умолчанию на 15 минут).
2. Счёт можно оплатить в Telegram, в браузере или по QR-коду.
3. После оплаты ключ появляется на сайте с анимацией. Он **также приходит покупателю в чат @CryptoBot** (скрытое сообщение счёта), даже если тот закрыл сайт.
4. Если счёт не оплачен вовремя, бронь снимается и ключ возвращается в продажу.

Сервер узнаёт об оплате двумя способами:
- **вебхук** (мгновенно, нужен публичный https-домен);
- **опрос CryptoBot** каждые 30 секунд и при открытой странице заказа. Этот способ работает даже на localhost.

Если оплата пришла в момент, когда ключи закончились, заказ получает статус «Оплачен, нет ключа». Когда вы добавите ключи этой игры, он выдастся автоматически.

## Публикация в интернете

1. Арендуйте VPS, установите Node.js 22+, скопируйте папку проекта (вместе с `.env` и `data/`).
2. Запустите сервер, например через pm2: `npx pm2 start server.js --name keyfall`.
3. Настройте домен и https через nginx + certbot (или Cloudflare) и проксируйте запросы на порт 3000.
4. В `.env` укажите `PUBLIC_URL=https://ваш-домен` и `TRUST_PROXY=true`, затем перезапустите сервер.
5. В @CryptoBot: Crypto Pay → Мои приложения → ваше приложение → Вебхуки → включить и вставить
   `https://ваш-домен/api/cryptopay/webhook`. Готовый адрес есть в админке на вкладке «Настройки».

## Настройки (`.env`)

| Параметр | Что значит |
|---|---|
| `CRYPTO_PAY_TOKEN` | токен приложения из @CryptoBot → Crypto Pay |
| `CRYPTO_PAY_NETWORK` | `mainnet` (реальные деньги) или `testnet` (@CryptoTestnetBot) |
| `ADMIN_PASSWORD` | пароль от админки |
| `PUBLIC_URL` | адрес сайта; от него зависят кнопка возврата из CryptoBot и вебхук |
| `SHOP_NAME` | название магазина на сайте |
| `FIAT` | валюта цен: `USD`, `EUR`, `RUB`… |
| `ACCEPTED_ASSETS` | какими монетами можно платить |
| `INVOICE_TTL_MIN` | сколько минут живёт счёт и бронь ключа |
| `GIVEAWAY_COOLDOWN_HOURS` | как часто один посетитель может забирать бесплатный ключ |
| `SUPPORT_URL` | ссылка на поддержку (например, `https://t.me/ваш_ник`), появится в футере и FAQ |
| `TRUST_PROXY` | `true`, если сайт стоит за nginx или Cloudflare |

После изменения `.env` перезапустите сервер.

## Безопасность и бэкапы

- `.env` содержит токен CryptoBot и пароль. Никому его не пересылайте и не выкладывайте в git (он уже в `.gitignore`).
  Если токен куда-то утёк, создайте новый в @CryptoBot и замените его в `.env`.
- Все игры, ключи и заказы хранятся в `data/db.json`. Регулярно копируйте этот файл. При каждом запуске сервер
  сам сохраняет копию в `data/db.json.bak`.
- Раздачи ограничены по IP: один ключ из каждой раздачи и не чаще раза в `GIVEAWAY_COOLDOWN_HOURS` часов.
